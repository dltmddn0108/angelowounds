---
description: 항목 한 개 또는 여러 개의 초고를 작성한다. 도메인만 받으면 항목 후보를 제안받는다.
argument-hint: <도메인>/<항목명> 또는 <도메인> 또는 <도메인>/<항목명>,<항목명>,...
---

`$ARGUMENTS` 형식 해석:

| 입력 | 동작 |
|---|---|
| `수학/영` | 단일 항목 초고 작성 |
| `수학/영,무한,미적분` | 여러 항목 일괄 작성 |
| `수학` | 도메인 안에 빠진 표제어 후보 10~20개를 제안하고, 사용자가 고른 것만 작성 |
| `수학 5` | 도메인에 빠진 항목 중 5개를 제안받아 동의 후 일괄 작성 |

절차:

1. `meta/themes.md`, `meta/style-guide.md`, `meta/glossary.md`를 읽는다.
2. `meta/outline.md`를 읽어 해당 도메인의 기존 항목 목록을 확인한다.
3. 동일 도메인의 기존 항목 1~3개를 읽어 톤·길이감을 확인한다.
4. 입력 형식에 따라:
   - 단일/복수 항목명이 명시된 경우: 바로 `drafter` 서브에이전트 호출.
   - 도메인만 받은 경우: drafter 에게 항목 후보 목록을 먼저 받아 사용자에게 보여주고, 어떤 것을 쓸지 확인.
5. `chapters/<도메인>/` 폴더가 없으면 만든다.
6. 동명 파일이 이미 있으면 덮어쓰지 말고 사용자에게 알린다.
7. 작성 후:
   - `meta/outline.md`의 해당 도메인 섹션에 한 줄씩 추가.
   - `meta/progress.md` 도메인 카운트 증가.
8. `drafter`가 남긴 `<!-- drafter note: ... -->`을 모아 사용자에게 요약 보고.

주의:
- 한 번에 여러 항목을 쓸 때는 톤·구조 일관성을 위해 항목 목록을 먼저 확정하고 일괄 작성.
- 임의로 commit 하지 말 것.
