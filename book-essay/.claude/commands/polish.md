---

`$ARGUMENTS` 윤문:

절차 (단일 항목):

1. 파일을 찾는다.
2. `.review.md` 가 있는지 확인. 없으면 "/review 를 먼저 돌리는 게 좋다"고 안내 (사용자가 강행 원하면 진행).
3. `polisher` 서브에이전트 호출. polisher는 Edit 권한으로 원고를 직접 수정.
4. 수정 전후의 diff를 요약 보고.
5. polisher가 남긴 `<!-- polisher: ... -->` 주석을 별도로 모아 보고.
6. `meta/progress.md` 갱신.

절차 (도메인 전체):

1. 도메인의 모든 항목에 위 절차 반복.
2. 도메인 단위 윤문 후, 도메인 안에서 같은 외래어·인명이 다르게 표기된 곳이 있는지 일괄 확인 (없으면 통과).
3. 도메인 통계 보고 (항목 N개, 총 수정 라인 수).

주의: 커밋은 사용자가 별도로 지시할 때만.
