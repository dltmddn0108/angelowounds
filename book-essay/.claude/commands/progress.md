진행 상황을 보고한다.

절차:

1. `chapters/` 아래 도메인 디렉터리 목록 확인 (`themes.md`의 도메인 목록 기준).
2. 각 도메인에 대해:
   - 항목 파일 수 (`.md` 중 `.review.md` / `.proofread.md` 제외)
   - 누적 글자 수 (한국어 기준 — 공백 제외 카운트)
   - `.review.md` 존재 비율
   - `.proofread.md` 존재 비율
3. 항목 단위 상태 분류:
   - `초고` — 본 파일만 존재
   - `검토` — `.review.md` 동반
   - `교정` — `.proofread.md` 동반
   - `완료` — 둘 다 동반 + (선택) 사용자 확정 표시
4. 표 형식 보고:
   ```
   ## 도메인별 요약
   | 도메인 | 항목 | 글자 | 검토 | 교정 |
   ```
5. 전체 누적 (모든 도메인 합계).
6. **인덱스 동기화**: `meta/outline.md` 의 항목 목록과 실제 파일이 일치하는지 확인. 누락된 항목이 있으면 추가하거나 사용자에게 알린다.
7. **다음에 손대면 좋을 도메인** 한 개를 추천 (예: 항목 수가 적거나 검토가 밀린 곳).

`$ARGUMENTS`로 도메인 하나를 받으면 그 도메인만 상세 보고 (항목별 한 줄씩).

주의:
- 추측으로 상태를 만들지 말 것. 파일이 없으면 `미확인`.
- `meta/progress.md` 의 도메인 카운트 표는 이 커맨드가 자동 갱신해도 된다 (사용자에게 갱신 사실 알림).
