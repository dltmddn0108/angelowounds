description: 전체 꼭지의 진행 상황을 표로 보여준다
---

전체 진행 상황을 요약해 주세요.

절차:

1. `meta/outline.md`를 읽어 전체 꼭지 목록을 확보한다.
2. `chapters/` 디렉터리의 파일 목록과 `meta/progress.md`를 교차 확인한다.
3. 각 꼭지에 대해 다음 상태 중 하나로 분류한다:
   - `미착수` — 파일 없음
   - `초고` — 파일 있음, review 기록 없음
   - `검토` — `.review.md` 있음, 윤문 흔적 없음
   - `완료` — 윤문 완료 표시 있음
4. 표 형식으로 보여준다:
   ```
   | # | 제목 | 상태 | 최근 업데이트 |
   ```
5. 전체 단어 수 혹은 글자 수(한국어 기준)를 간단히 집계해 표 아래 덧붙인다.
6. 다음에 손대면 좋을 꼭지를 한 개만 추천한다.

주의: 추측으로 상태를 만들지 말 것. 파일/진행 기록이 없으면 솔직하게 `미확인`이라고 표시한다.
