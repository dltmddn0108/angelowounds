`$ARGUMENTS` 검토:

| 입력 | 동작 |
|---|---|
| `수학/영` | 단일 항목 3중 검토 (순차) |
| `수학` | 도메인 전체 일괄 검토. fact-checker 만 병렬, 나머지는 항목별 순차 |

절차 (단일 항목):

1. 파일을 찾는다. 없으면 중단.
2. `structure-critic` → 결과 보고 → 사용자가 반영
3. `style-critic` → 결과 보고 → 사용자가 반영
4. `fact-checker` → 결과 보고
5. 세 리뷰의 핵심을 묶어 요약.
6. 각 리뷰 결과를 `chapters/<도메인>/<항목>.review.md` 에 보관.

절차 (도메인 전체):

1. 도메인 디렉터리의 모든 항목 파일 목록.
2. 각 항목에 위 1~6 절차 적용.
3. **fact-checker는 도메인 단위 일괄 호출 가능** — 항목 간 사실이 서로 의존하는 경우(예: 같은 인물·연도가 여러 항목에 등장) 일관성도 함께 본다.
4. 도메인 전체 요약 보고: 항목별 점수 매트릭스 (구조 / 문체 / 사실 각각 OK/문제/심각).

주의:
- 에이전트 역할 경계를 넘는 지적이 보이면 사용자에게 알리고 재요청.
- 원고는 이 커맨드에서 수정하지 않는다.
- 도메인 전체 리뷰는 큰 작업이다. 사용자가 도메인을 입력하면 항목 수와 예상 시간을 먼저 알리고 확인.
