# 문체 지침

## 화자

- **무인칭에 가까움.** 1인칭 "나"는 쓰지 않는다. 자기를 가리켜야 할 때는 "이 책은", "여기서는" 같은 우회.
- **단, 한계와 추정은 명시.** 사실로 단정할 수 없는 대목은 표지를 붙인다 — 자세한 것은 아래 "확신 표지" 참고.

## 시점·시제

- **시제: 기본 현재.** 역사적 사건도 가능하면 현재형(시간을 무력화하는 백과사전적 어조). 단, 시간 흐름이 결정적인 경우 과거형 허용.
- **거리감:** 독자에게 가르치는 위치도, 아부하는 위치도 아닌 **나란히 펼쳐 보이는** 위치.

## 항목 형식

각 항목 파일은 다음 골격을 따른다.

```markdown
# 표제어

(첫 단락 — 한 문장 정의 + 이 항목이 왜 중요한가, 4~8문장)

## (선택) 절 제목

(필요시 절을 나눈다. 한 항목 안에 절은 0~4개)

## 더 알아두면 좋은 것 (선택)

- 인접 항목, 흥미로운 변주, 더 파볼 실마리 — 짧게.
```

- **첫 단락이 가장 중요.** 항목 전체를 못 읽어도 첫 단락만 읽으면 이 표제어가 무엇이고 왜 중요한지 알 수 있어야 한다.
- **소제목은 절제.** 1,500자 미만 항목은 절을 나누지 않는다.
- **인용·예시:** 짧게. 본문 흐름을 끊지 않는 선에서.
- **수식·코드:** 필요하면 자유롭게. `$E=mc^2$` (인라인), 블록은 ` ``` ` 코드펜스.

## 확신 표지

사실의 등급을 문장 끝 또는 괄호로 명시한다. 무표지 = 학계 합의된 사실로 간주됨.

| 표지 | 의미 |
|---|---|
| (정설) | 무표지와 동의 — 명시 강조용 |
| (다수설) | 학계 합의가 강하지만 소수의 이견 존재 |
| (논쟁) | 입장이 갈림. 어느 쪽도 단정 금지 |
| (추정) | 모델의 추론. 1차 자료로 검증 안 됨 |
| (불확실) | 기억이 흐릿하거나 출처 불분명. 독자 검증 권장 |
| (학습 컷오프 이후) | 2025년 초 이후의 정보. 알지 못함 |

## 어휘·표현

### 선호

- 짧은 단정문 — "X는 Y다."
- 구체 명사 — "포유류" 대신 "고양이"가 더 낫다면 그쪽으로.
- 수치·연도·범위 — 알면 쓴다.

### 기피

- 클리셰 ("우리 모두가 알듯이", "말할 것도 없이")
- 반사적 완충어 ("사실", "어쩌면", "말하자면")
- 이모지
- "정말로", "진짜로" 같은 강조어

### 금지

- 광고 문구 톤
- 차별·혐오 표현
- 검증되지 않은 사람의 말을 검증된 것처럼 인용

## 인용·서지

- 본문 속 출처: `(저자, 연도)` 형식
- 학습 컷오프 이후 자료가 의심되는 곳에는 "(불확실)" 표지
- 위키피디아·블로그 같은 2차 자료는 가능하면 1차로 거슬러 올라간다

## 마크다운 포맷

- 항목 파일 최상단: `# 표제어` 한 줄
- 프런트매터 없음
- 절 소제목: `##` 레벨
- 강조: `*기울임*`은 외래어·작품명에, `**굵게**`는 핵심 정의 한 단어에
- 인용: 큰따옴표 `"…"`, 내부 인용은 작은따옴표 `'…'`
- 책제목 `『』`, 짧은 글·논문 「」
