# 통일성의 축

이 책은 일반적 의미의 "한 권"이 아니다. **한 인공지능(Claude)의 인식 지도**를 사용자가 캐묻고 골라 편집한 협업 백과사전이다.

## 통일성을 만드는 것

세 가지가 통일성을 만든다.

1. **시점 — 한 LLM의 카테고리.** 항목의 분류·강조·생략은 학계 표준이 아니라 한 모델이 어떻게 세계를 보관하고 있는가를 따른다.
2. **목소리 — 단정적이되 한계를 명시.** 추정과 사실, 합의된 지식과 모델의 편향을 표지로 구분한다.
3. **편집의 흔적 — 사용자가 무엇을 캐물었는가.** 항목이 추가된 순서·배치·코멘트 자체가 책의 골격이다.

## 다루지 않을 것

- **시간상 한계 너머의 것.** 학습 컷오프(2025년 초) 이후의 사건·인물·작품. 모르는 것은 모른다고 적는다.
- **개인정보·민감 영역.** 실존 인물의 사적 정보, 위험한 기술적 세부.
- **완벽한 사실 검증을 전제하는 영역.** 의료·법률·재무는 항목이 있어도 "참고용, 검증 필요" 표지를 붙인다.

## 형식

- **항목(entry)이 단위.** 분량 800~5,000자 (필요시 더). 각 항목은 독립적으로 읽힌다.
- **도메인(domain)이 묶음.** 항목들은 도메인 디렉터리에 모인다. 도메인 간 교차 참조는 자유.
- **순서가 의미를 만들지 않음.** 펼쳐 읽는 책. 단, 각 도메인 안에서는 자모순 또는 추가 순서로 정렬.

## 도메인 (10개)

1. `자연` — 물리, 화학, 생물, 지구·우주
2. `수학` — 수, 도형, 구조, 증명, 계산
3. `역사` — 사건, 인물, 시대 흐름
4. `언어` — 한국어·다른 언어들·언어 일반
5. `예술` — 문학·시각예술·음악·영화
6. `기술` — 컴퓨터·공학·발명
7. `철학` — 사유의 전통·개념·논쟁
8. `인간` — 심리·사회·문화·인류학
9. `일상` — 음식·도구·습관·놀이
10. `기타` — 위 어디에도 안 맞는 것

도메인은 필요하면 늘어난다. 한 항목이 두 도메인에 걸치면 더 어울리는 쪽에 두고 다른 쪽에서 참조한다.
