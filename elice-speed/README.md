# Elice Speed Control

엘리스(elice.io) 강의 영상에 커스텀 배속을 적용하는 모바일 최적화 도구.

## Features

- **플로팅 버블 UI** — 드래그로 위치 이동, 탭으로 패널 열기/닫기
- **슬라이더 + 직접 입력** — 0.25 ~ 8x 슬라이더 또는 0.1 ~ 16x 직접 입력
- **프리셋 칩** — 1x, 1.25x, 1.5x, 2x, 2.5x, 3x, 4x, 5x 원탭 적용
- **롱프레스 부스트** — 영상 오른쪽 절반을 0.4초 이상 누르면 5x 임시 배속, 손 떼면 복귀
- **영상 위 오버레이** — 현재 배속을 영상 좌상단에 표시
- **남은시간 표시** — 현재 배속 기준 남은 시청시간 실시간 계산
- **배속 리셋 방어** — 플레이어가 배속을 되돌려도 자동 재적용
- **동적 video 감지** — SPA 라우팅으로 새 video가 나타나면 자동 적용
- **햅틱 피드백** — 프리셋/부스트 시 진동 (Vibration API 지원 기기)

## 제공 파일

| 파일 | 용도 |
|------|------|
| `bookmarklet.min.js` | 북마크릿 (복붙용, `javascript:` 접두어 포함) |
| `bookmarklet.src.js` | 북마크릿 원본 소스 (가독성용) |
| `elice-speed.user.js` | 유저스크립트 (Tampermonkey/Violentmonkey) |

## 설치 가이드

### iOS Safari (북마크릿)

1. Safari에서 아무 페이지나 북마크에 추가
2. 북마크 편집 → URL을 `bookmarklet.min.js` 내용 전체로 교체
3. 엘리스 강의 페이지에서 북마크 탭 → 보라색 버블 등장

### Android Kiwi Browser / Firefox (유저스크립트)

1. Kiwi Browser에서 Tampermonkey, 또는 Firefox에서 Violentmonkey 설치
2. `elice-speed.user.js` raw 파일 접속 → 자동 설치
3. 엘리스 접속 시 video 감지되면 버블 자동 표시

### Android Chrome (제한적)

주소창 `javascript:` 차단됨 → PC Chrome에서 북마크 생성 후 계정 동기화.

## 사용법

1. 보라색 버블 탭 → 패널 펼침
2. 슬라이더 드래그 또는 숫자 직접 입력 → 적용
3. 프리셋 칩 탭하면 즉시 적용
4. 영상 오른쪽 절반 길게 누르면 5x 임시 부스트 (손 떼면 복귀)
5. 버블은 드래그로 원하는 위치로 이동 가능 (유저스크립트는 위치 기억)

## 제한 사항

- cross-origin iframe 내 플레이어는 제어 불가
- 4x 이상에서 음성 품질 저하 가능
- DRM 보호 콘텐츠는 브라우저 허용 범위 내에서만 동작

## 본 도구가 하지 않는 것

- 서버 진도/시청시간 API 조작 안 함
- 로그인/인증 정보 접근 안 함
- 외부로 데이터 전송 안 함 (순수 클라이언트 사이드)
