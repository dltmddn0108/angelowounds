# 독서노트: 리팩터링 2판

마틴 파울러의 리팩터링 2판 (JavaScript 예제 기반).

## 핵심 메시지

> 리팩터링은 코드의 외부 동작을 바꾸지 않으면서 내부 구조를 개선하는 것이다.

## 자주 쓰는 리팩터링 기법

1. **함수 추출하기** (Extract Function)
2. **변수 인라인하기** (Inline Variable)
3. **함수 옮기기** (Move Function)
4. **조건부 로직을 다형성으로** (Replace Conditional with Polymorphism)

## 테스트와의 관계

리팩터링 전에 반드시 테스트를 작성해야 한다.
테스트 없는 리팩터링은 무모한 도박이다.

> [!important] "리팩터링할 때는 두 개의 모자를 쓰지 마라"
> 기능 추가와 리팩터링을 동시에 하지 말 것.

## 코드 냄새 목록

- 긴 함수
- 거대한 클래스
- 데이터 뭉치 (Data Clumps)
- 산탄총 수술 (Shotgun Surgery)
- 기능 편애 (Feature Envy)

디자인 패턴과 리팩터링은 서로 보완적인 관계다.
패턴은 목표를, 리팩터링은 목표에 도달하는 경로를 제공한다.
