# 리액트 훅

리액트 16.8에서 추가된 훅은 함수형 컴포넌트에서 상태와 생명주기를 다룰 수 있게 해준다.

## 기본 훅

- `useState`: 로컬 상태 관리
- `useEffect`: 부수효과 처리
- `useMemo`: 비싼 연산 결과 캐시

```tsx
const [count, setCount] = useState(0);
```

예를 들어 `리액트 훅을 사용할 때` 규칙을 지키지 않으면 경고가 나온다.

## 자주 하는 실수

- 조건문 안에서 훅을 부르는 것
- 의존성 배열을 빠뜨리는 것
