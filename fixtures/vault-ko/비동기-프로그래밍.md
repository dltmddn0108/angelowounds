# 비동기 프로그래밍

자바스크립트는 싱글 스레드이지만 비동기 처리를 통해 논블로킹 I/O를 구현한다.

## 콜백에서 Promise로

```js
// 콜백 지옥
getData(function(a) {
  getMore(a, function(b) {
    getEvenMore(b, function(c) {
      console.log(c);
    });
  });
});

// Promise 체이닝
getData()
  .then(a => getMore(a))
  .then(b => getEvenMore(b))
  .then(c => console.log(c));
```

## async/await

ES2017에서 도입된 `async`/`await`는 비동기 코드를 동기 코드처럼 읽을 수 있게 한다.

```ts
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    return await response.json();
  } catch (error) {
    console.error('Failed to fetch:', error);
  }
}
```

> [!warning] `useEffect` 안에서 async 함수를 직접 전달하면 안 된다.
> 내부에서 별도의 async 함수를 선언하고 호출해야 한다.

## 관련 개념

성능최적화를 할 때 불필요한 리렌더링을 막으려면 비동기 데이터 페칭의
타이밍을 잘 관리해야 한다.
