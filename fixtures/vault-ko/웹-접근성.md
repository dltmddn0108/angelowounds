# 웹 접근성 (a11y)

모든 사용자가 웹 콘텐츠에 접근할 수 있도록 보장하는 것.

## WCAG 핵심 원칙

1. **인식 가능**: 텍스트 대안, 자막 제공
2. **운용 가능**: 키보드 접근, 충분한 시간
3. **이해 가능**: 읽기 쉬운 텍스트, 예측 가능한 동작
4. **견고함**: 다양한 보조 기술과 호환

## 리액트에서의 접근성

```tsx
// aria-label 사용
<button aria-label="메뉴 닫기" onClick={onClose}>
  <XIcon />
</button>

// 시맨틱 HTML 사용
<nav aria-label="주요 네비게이션">
  <ul>
    <li><a href="/">홈</a></li>
  </ul>
</nav>
```

컴포넌트 설계 단계에서부터 접근성을 고려해야 나중에 대규모 수정을 피할 수 있다.

## 테스트

- `eslint-plugin-jsx-a11y`: 정적 분석
- `axe-core`: 런타임 감사
- 스크린 리더(NVDA, VoiceOver)로 수동 테스트
