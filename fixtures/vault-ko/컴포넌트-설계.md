# 컴포넌트 설계 원칙

좋은 리액트 컴포넌트는 단일 책임 원칙을 따른다.

## 핵심 원칙

1. **단일 책임**: 하나의 컴포넌트는 하나의 역할만
2. **합성 우선**: 상속보다 합성을 선호
3. **제어 역전**: 부모가 동작을 결정하도록

## Props 설계

```tsx
// 나쁜 예: 너무 많은 props
interface BadProps {
  title: string;
  showIcon: boolean;
  iconSize: number;
  iconColor: string;
}

// 좋은 예: 합성 패턴
interface GoodProps {
  title: string;
  icon?: React.ReactNode;
}
```

> [!tip] 컴포넌트가 props를 5개 이상 받으면 분리를 고려하자.

## 상태 관리와의 관계

로컬 상태는 `useState`로 충분하지만, 여러 컴포넌트가 공유하는 상태는
전역 상태 관리 도구가 필요하다. Zustand나 Jotai 같은 경량 라이브러리가 인기다.

리액트 훅의 규칙을 잘 지키면 커스텀 훅으로 로직을 깔끔하게 분리할 수 있다.
