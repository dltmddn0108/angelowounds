# 모던 웹 개발

현대 웹 개발의 전체적인 흐름과 핵심 기술 스택을 정리한다.

## 프론트엔드

React가 여전히 가장 많이 사용되는 프레임워크다. React Hooks의 도입으로 함수형 컴포넌트가 표준이 되었고, TypeScript와의 조합이 사실상 필수가 되었다.

레이아웃은 CSS Grid와 Flexbox 조합으로 구성하며, Tailwind CSS 같은 유틸리티 프레임워크의 사용이 늘고 있다.

## 백엔드

Node.js 기반의 서버가 풀스택 JavaScript/TypeScript 환경에서 인기가 높다. REST API 설계 원칙을 따르되, GraphQL이나 tRPC도 대안으로 고려할 수 있다.

데이터베이스는 PostgreSQL이 범용적으로 가장 강력하다. Redis를 캐시 레이어로 함께 사용하는 구성이 일반적.

## DevOps

Docker로 컨테이너화하고, CI/CD 파이프라인을 통해 자동 배포하는 것이 표준. Git 워크플로우는 GitHub Flow나 trunk-based가 주류.

## 품질 관리

테스트 전략은 피라미드 구조를 따른다. 단위 테스트를 두껍게 작성하고 E2E 테스트는 핵심 플로우만. 보안은 OWASP Top 10을 기본으로 체크.

## 성능

Performance Optimization은 Core Web Vitals 기준으로 측정한다. 번들 크기 관리, 코드 스플리팅, 이미지 최적화가 핵심.

## 함수형 프로그래밍의 영향

함수형 프로그래밍 패러다임은 프론트엔드와 백엔드 모두에 깊은 영향을 미쳤다. 불변성, 순수 함수, 합성은 이제 일상적인 코딩 원칙이다.

## 학습 로드맵

1. JavaScript 기초 (특히 클로저, 비동기)
2. TypeScript 도입
3. React + Hooks
4. Node.js 서버 개발
5. 데이터베이스 설계
6. Docker + CI/CD
7. 디자인 패턴과 아키텍처
8. 테스트와 보안

> [!info] 끝이 없는 여정
> 웹 개발 생태계는 빠르게 변한다. 기본기를 탄탄히 하되, 새로운 도구와 패턴에 열린 자세를 유지하는 것이 중요하다.
