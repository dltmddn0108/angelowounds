# 모던 웹 개발 개요

2024년 기준 프론트엔드/풀스택 웹 개발의 핵심 기술과 흐름을 정리한다.

## 프론트엔드

- **React / Next.js**: 컴포넌트 기반 UI. React Hooks로 상태와 부수효과를 관리.
- **TypeScript**: 정적 타입으로 대규모 코드베이스의 안정성 확보.
- **CSS-in-JS / Tailwind**: 유틸리티 퍼스트 CSS가 대세.

## 백엔드

- **Node.js**: JavaScript로 서버를 작성. 이벤트 루프 기반 비동기 처리.
- **REST / GraphQL**: API 설계 패턴. REST가 여전히 주류.
- **데이터베이스**: PostgreSQL + Prisma ORM 조합이 인기.

## DevOps

- **Docker**: 컨테이너화로 환경 일관성 확보.
- **CI/CD**: GitHub Actions로 자동 빌드/테스트/배포.
- **Git**: Trunk-based 개발이 빠른 배포 주기에 적합.

## 코드 품질

- **테스트**: Vitest(단위), Playwright(E2E)
- **린터**: ESLint + Prettier
- **타입 체크**: `tsc --noEmit`

## 보안

웹 보안은 개발 초기부터 고려해야 한다.
XSS, CSRF, SQL 인젝션 같은 기본적인 공격 벡터를 이해하고
방어 코드를 습관적으로 작성해야 한다.

> [!note] 기술 스택 선택보다 중요한 것은 팀의 역량과 유지보수 가능성이다.
> 유행하는 기술이 아니라 팀이 잘 아는 기술을 선택하자.
