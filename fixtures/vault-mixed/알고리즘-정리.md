# 알고리즘 정리

코딩 인터뷰와 실무 모두에서 필요한 핵심 알고리즘과 시간 복잡도 정리.

## 시간 복잡도 (Big O)

$$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(2^n) < O(n!)$$

실무에서 가장 자주 마주치는 것은 $O(n)$과 $O(n \log n)$이다.

## 정렬 알고리즘

| 알고리즘 | 평균 | 최악 | 공간 |
|---------|------|------|------|
| Quick Sort | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ |
| Merge Sort | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ |
| Heap Sort | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ |

## 탐색 알고리즘

### 이진 탐색 (Binary Search)

정렬된 배열에서 $O(\log n)$으로 탐색 가능.

```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

### BFS / DFS

그래프 탐색의 기본. BFS는 최단 경로, DFS는 전체 탐색에 적합하다.

## 동적 프로그래밍 (DP)

큰 문제를 작은 하위 문제로 분할하여 해결. 메모이제이션(top-down)과 타뷸레이션(bottom-up) 두 가지 접근법이 있다.

$$dp[i] = \min_{j < i}(dp[j] + cost(j, i))$$

클로저를 활용한 메모이제이션은 JavaScript Closures에서 다루는 핵심 패턴이기도 하다.

## 실전 팁

데이터베이스의 인덱스도 B-Tree 기반이므로 탐색 알고리즘의 이해가 쿼리 최적화에 직접 도움이 된다.
