# 프로젝트 회고: 쇼핑몰 리뉴얼

2024년 1분기 진행한 쇼핑몰 리뉴얼 프로젝트 회고.

## 잘한 점

- **Git 워크플로우 정비**: GitHub Flow를 도입하고 PR 리뷰를 의무화했다. 코드 품질이 눈에 띄게 향상됨.
- **테스트 커버리지 향상**: 핵심 비즈니스 로직의 단위 테스트를 80% 이상으로 올렸다. Vitest 도입이 큰 도움.
- **Docker 기반 개발 환경**: Docker Compose로 로컬 개발 환경을 통일했다. 온보딩 시간이 하루에서 1시간으로 단축.

## 아쉬운 점

- E2E 테스트를 도입하려 했으나 일정 부족으로 미루게 됨
- CI/CD 파이프라인 구축이 예상보다 오래 걸림
- 성능 최적화를 후반에 몰아서 하게 됨 (초반부터 했어야)

## 기술적 결정

TypeScript 전면 도입은 초기 비용이 컸지만, 프로젝트 중반부터 버그가 현저히 줄었다. React Hooks 기반으로 리팩토링하면서 컴포넌트 재사용성도 크게 개선.

데이터베이스는 PostgreSQL을 선택했고, Prisma ORM을 사용. N+1 쿼리 문제를 몇 번 겪었지만 `include`와 `select`로 해결.

## 다음에 개선할 것

1. 프로젝트 초반에 CI/CD Pipeline부터 구축
2. 성능 모니터링 도구(Sentry, DataDog) 조기 도입
3. API 문서화를 OpenAPI 기반으로 자동화
4. Security Best Practices 체크리스트 도입

## 결론

전체적으로 성공적인 프로젝트였다. 기술 부채를 줄이면서 새로운 도구를 도입한 좋은 경험.
