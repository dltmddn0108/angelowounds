# 함수형 프로그래밍

함수형 프로그래밍(FP)은 순수 함수와 불변 데이터를 중심으로 프로그램을 구성하는 패러다임이다.

## 핵심 개념

### 순수 함수 (Pure Functions)

동일한 입력에 항상 동일한 출력을 반환하고, 부수 효과(side effect)가 없는 함수.

```typescript
// 순수 함수
const add = (a: number, b: number): number => a + b;

// 비순수 함수 - 외부 상태에 의존
let total = 0;
const addToTotal = (n: number) => { total += n; return total; };
```

### 고차 함수 (Higher-Order Functions)

함수를 인자로 받거나 함수를 반환하는 함수. [[JavaScript Closures]]가 이를 가능하게 한다.

```typescript
const pipe = (...fns: Function[]) =>
  (x: any) => fns.reduce((acc, fn) => fn(acc), x);

const process = pipe(
  (s: string) => s.trim(),
  (s: string) => s.toLowerCase(),
  (s: string) => s.split(' ')
);
```

### 불변성 (Immutability)

데이터를 직접 변경하지 않고 새로운 복사본을 만든다. React의 상태 관리에서 이 원칙이 핵심적이다.

## 실전 활용

TypeScript와 함께 사용하면 타입 안전성과 함수형 패러다임의 장점을 동시에 얻을 수 있다. `fp-ts` 라이브러리를 활용하면 Either, Option 같은 대수적 타입도 사용 가능하다.

## 디자인 패턴과의 관계

FP에서도 패턴이 존재한다. Strategy 패턴은 고차 함수로 자연스럽게 구현되고, Observer 패턴은 reactive stream으로 대체된다. [[디자인-패턴]] 참고.
